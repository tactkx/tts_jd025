# tts_jd025

**把语音合成工程师·工具调用的参数错配归并成组并标出每组的代表项。**

`tts_jd025` —— 按结构键把条目聚类，标出语音合成工程师·工具调用的参数错配上的同组项与各组的代表样本

- 零依赖，Python 3.10+ 标准库即可运行
- 单文件，`tts_jd025.py` 拷走就能用
- 不联网、不写文件

## 对应的岗位

- 目标岗位：**Anthropic · 初级语音合成工程师**
- 技能主线：语音、Python、推理加速
- 领域标签：语音
- 研究方向：语音合成工程师·工具调用的参数错配

工具里的规则表就是照着上面这条岗位要求建的——每条规则都挂在技能线或领域标签上，命中时能指回具体要求。

## 安装

零依赖，Python 3.10+ 即可：

```bash
pip install tactkx-tts_jd025
```

装完直接用命令名调用：

```bash
tts_jd025 --help
```

也可以不用安装，直接把 `tts_jd025.py` 拷走用——它只依赖标准库。

## 为什么需要它

分组依据是结构特征而不是字面相似，改了措辞但结构没变的仍算同组

它遵守下面几条自己定的规矩：

1. **只报告能定位到具体位置的结论**，不做语义猜测。
2. **规则表公开**，每条命中都能对应到岗位要求的一条明示规则。
3. **输入为空或格式不对时明确报错**，不静默返回空结果。

## 用法

```bash
python tts_jd025.py --file input.txt
python tts_jd025.py --text "示例内容"
python tts_jd025.py --file input.txt --json
```

加 `--json` 可以拿到机器可读的结果，便于接到流水线里。
